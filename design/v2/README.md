# Storefront v2 design

Designs for issue #60: every storefront page, component and editor block rebuilt on the ArtisanPack UI design system.

- `screens/` – screenshots of the approved boards (light, dark and mobile).
- `specs/<issue>.md` – the short design spec for each rebuild sub-issue (#72–#151).
- `post-specs.sh` – posts each spec as a comment on its sub-issue with `gh`.

The full canvas, with high-contrast and right-to-left boards for every page, is the source of truth:
https://claude.ai/code/artifact/1433c967-7beb-45a4-8e05-e2785d8f8e57

The screenshots use a fictional store (Field & Kiln) with photos from Unsplash.
