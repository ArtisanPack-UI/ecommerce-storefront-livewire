# Reference

Lookup material for the storefront: the registries, hooks, and events it exposes, its Artisan commands, its configuration keys, its Blade components, and every route.

- [Hooks](reference/hooks.md): every registry, filter, and action the storefront uses, and the Livewire events its components exchange.
- [Artisan commands](reference/commands.md): `ecommerce-storefront:install` and the engine commands a store uses with the storefront.
- [Configuration](installation/configuration.md): every key in `config/artisanpack/ecommerce-storefront-livewire.php`, and the store settings that override them.
- [Blade components](extending/blade-components.md): every `x-artisanpack-ec-*` component and its props.
- [Embedding components](extending/embedding-components.md): every storefront Livewire component and the properties it takes.
- [Screens](usage/screens.md): every storefront and account path and route name.
- [Blocks](visual-editor/blocks.md): every commerce block and its attributes.
